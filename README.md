# Object-Oriented Programming (OOP) Lab Programs

## Overview

This repository contains the Object-Oriented Programming (OOP) programs I completed during my **2nd semester** at university. These programs were developed as part of my coursework to understand and apply the core principles of Object-Oriented Programming using C++.

The repository demonstrates a wide range of OOP concepts through practical lab assignments and programming exercises.

## Topics Covered

* Classes and Objects
* Constructors and Destructors
* Encapsulation
* Abstraction
* Inheritance
* Polymorphism
* Function Overloading
* Operator Overloading
* Function Overriding
* Friend Functions and Friend Classes
* Static Data Members and Member Functions
* Dynamic Memory Allocation
* Pointers and Objects
* Arrays of Objects
* File Handling
* Exception Handling
* Templates
* Virtual Functions
* Abstract Classes
* Composition and Aggregation

## Repository Structure

Each program is organized as a separate source file, with each file focusing on a specific OOP concept or lab assignment. The repository serves as a collection of my academic work and programming practice throughout the semester.

## Purpose

This repository was created to:

* Strengthen my understanding of Object-Oriented Programming concepts.
* Practice problem-solving using C++.
* Maintain a record of my university lab work.
* Showcase my learning journey and programming skills.
